# Modifier v0.11.4 - series length for Kick-Off Weekend and the EWC

Requires game beta.33+. Builds on v0.11.3.

## Fixed
- **Kick-Off Weekend and the Esports World Cup now follow the series length setting** (Quickest / Shortened / Authentic). They were fixed at Bo5 groups and Bo7 playoffs. Kick-Off plays like a Major, the EWC like Worlds. Authentic is unchanged; Shortened and Quickest are shorter.
- Changing the setting (Edit Save) also changes the matches of these events that are not played yet. Saving Edit Save repairs an event that was drawn with old values. A series you have already started stays as it is.

## Notes for testers
Checked in tests, not by eye in the real game: with Shortened, an unplayed Kick-Off group match should be Best of 3.
